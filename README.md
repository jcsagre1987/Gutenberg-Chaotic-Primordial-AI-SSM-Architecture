# Gutenberg-Chaotic-Primordial-v0.3.0-AI-SSM-Architecture-
Gutenberg Chaotic Primordial v0.3.0 is an experimental hybrid AI architecture combining Selective State-Space Models (SSM) and Dual-Stream Delta-Rule Associative Memory for sequence processing, persistent state dynamics, and stateful streaming inference. Built with portable PyTorch for CPU and CUDA.
